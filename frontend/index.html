AegisAgent 智盾

面向大模型智能体的全链路行为监督与安全审计平台

作品聚焦提示注入、工具调用劫持、越权文件访问、上下文污染与 API 滥用等智能体应用风险， 通过运行时事件采集、策略引擎、文档安全扫描、红队评测和可解释告警，为大模型应用提供可落地的安全监督能力。

7 类红队攻击场景

核心创新点

文档内容级提示注入检测 在文档进入 LLM 上下文前识别隐藏指令、伪系统提示和越权诱导。
工具调用前置授权 对 file.read、file.write、API request 等动作进行实时策略判断。
证据化攻击链 将上传、解析、扫描、模型调用和工具调用串联成可解释溯源链。
红队评测闭环 内置提示注入、上下文污染、越权文件读取、API 参数遍历样本。

后端基于 FastAPI 与 SQLite 实现 MVP，前端控制台直接调用 REST API，当前已支持文本、PDF、DOCX 样本扫描与红队评测。

参赛方向对应

面向大模型及其应用的安全性研究 覆盖提示注入、工具调用劫持、记忆/上下文污染、行为监督和阻断记录。
基于大语言模型的应用安全审计技术 覆盖 API 请求行为审计、异常调用检测、可解释告警和评测结果展示。
